# Changelog

Notable changes to this project are documented here.

## 1.0.0 - 2026-11-05

- Added the top-down football-inspired file upload interaction.
- Added drag-to-aim pointer controls, moving defenders, and a moving goalkeeper.
- Added file picker, drag-and-drop, file preview token, and success/error states.
- Added optional multipart upload endpoint configuration and a local Express example.
- Added project documentation, MIT license, GitHub Actions, CodeQL, and Dependabot configuration.
