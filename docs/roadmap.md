# Roadmap ideas

This is a small interaction experiment, so the roadmap is intentionally lightweight. These are possible community contributions rather than delivery commitments.

## Gameplay and customization

- Expose field colors, team colors, difficulty, and shot physics through a small configuration object.
- Offer optional layouts and sizes for embedding the interaction in different products.
- Add a fully keyboard-operable aiming mode and more explicit screen-reader status announcements.
- Add automated browser tests for file selection, dragging, shooting, scoring, and upload failures.

## Integrations

- Add a storage-provider example using S3-compatible object storage.
- Document signed upload URLs for applications that should not proxy file bytes through their own server.
- Add a reusable web-component wrapper once the public API is stable.

Have an idea? Open a feature request and describe the use case before proposing a large implementation.
